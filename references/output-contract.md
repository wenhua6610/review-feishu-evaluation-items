## 对话输出

严格按以下顺序输出；没有内容的部分写“无”，不要省略材料完整性和未读材料。

```markdown

- 结论：通过 / 不通过 / 待确认 / 无法审查
- 材料完整性：完整 / 基本完整 / 不完整 / 无法审查
- 适用规则版本：
- 审查题目数：
- 一句话说明：

## 2. 材料覆盖情况
- 已读取飞书材料：

- 已解析附件：
- 已解压压缩包：
- 未成功读取材料：
- 遍历边界或限制：

## 3. 适用规则
| 规则ID | 要求摘要 | 强制程度 | 来源定位 | 适用对象 |
|---|---|---|---|---|

## 4. 逐题结果
### Q-001 — 不通过

2. 规则依据：
3. 题目证据：

## 5. 给出题老师的话术
```

题目数量较多时，先给汇总表，再展开所有不通过和待确认题；通过题可以只列 ID 和“通过”，但不得隐藏其适用规则范围。

## 老师话术

使用以下结构：

```text
老师您好，[题目ID]目前有一处需要调整：
[具体位置和问题]。
根据[规则名称/规则ID/定位]，[规则要求]。
建议[明确修改动作]，修改时请保持原有考查目标不变。
完成后请重新提交审核。
```

话术要求：

- 尊重、客观，不评价老师能力；
- 使用明确名词，不写“这里”“上述内容”等模糊指代；
- 不只说“请优化”“不够清晰”“不符合要求”；
- 不暴露内部临时路径、哈希、工具报错或账号信息；
- 不把附件无权限归咎于老师，改为请求补充权限或材料；
- 多个问题按题目和位置分条；
- 二次复审时说明“仍未满足的具体点”，不要重复整段首次话术。

## 无问题时

不要只写“全部通过”。至少说明：

- 使用了哪一版本规则；
- 审查了哪些题目组成部分；
- 材料完整性；
- 是否存在不影响结论的限制；
- 当前范围内未发现违反强制规则的问题。
